## Как пользоваться

1. Запусти **Assassin's Creed IV Black Flag** (сборка **ACBFResynced**)  
2. Запусти трейнер  
3. Дождись подключения к `ACBlackFlag.exe`  
4. Выбери категорию: Kenway / Jackdaw / Combat / Economy / World  
5. Включай функции хоткеями **NumPad** или тумблерами  
6. Язык UI: **EN** / **RU**

| Клавиша | Действие |
|---------|----------|
| `Num …` | Вкл / выкл чита |
| `Ctrl + Shift + Home` | Master Off — выключить всё |
