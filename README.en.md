## How to use

1. Launch **Assassin's Creed IV Black Flag** (**ACBFResynced** build)
2. Launch the trainer
3. Wait until it attaches to `ACBlackFlag.exe`
4. Open a category: Kenway / Jackdaw / Combat / Economy / World
5. Toggle features with **NumPad** keys or UI switches
6. UI language: **EN** / **RU**

| Key | Action |
|---------|----------|
| `Num …` | Toggle |
| `Ctrl + Shift + Home` | Master Off |
