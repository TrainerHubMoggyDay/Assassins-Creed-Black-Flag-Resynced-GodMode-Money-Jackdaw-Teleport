## Cara pakai

1. Jalankan **Assassin's Creed IV Black Flag** (**ACBFResynced**)
2. Jalankan trainer
3. Tunggu koneksi ke `ACBlackFlag.exe`
4. Pilih kategori: Kenway / Jackdaw / Combat / Economy / World
5. Aktifkan dengan **NumPad** atau sakelar
6. Bahasa UI: **EN** / **RU**

| Tombol | Aksi |
|---------|----------|
| `Num …` | On / off |
| `Ctrl + Shift + Home` | Master Off |
