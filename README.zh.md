## 使用方法

1. 启动 **Assassin's Creed IV Black Flag**（**ACBFResynced**）
2. 启动训练器
3. 等待连接到 `ACBlackFlag.exe`
4. 选择分类：Kenway / Jackdaw / Combat / Economy / World
5. 用 **NumPad** 或开关启用功能
6. 界面语言：**EN** / **RU**

| 按键 | 作用 |
|---------|----------|
| `Num …` | 开关 |
| `Ctrl + Shift + Home` | 全部关闭 |
